# 通知记录

> 用于记录 G0-G8 Lark / webhook 阶段通知。实际发送后填写；dry-run 不等于已通知。

| 时间 | 门禁 | 状态 | 摘要 | 方式 | 结果 |
|------|------|------|------|------|------|
| 暂无 | - | - | 当前未启用主动通知，未发送真实群消息 | - | skipped |

## 规则

- 同一门禁同一状态不要重复发，除非内容有实质变化。
- 发送失败记录 `failed` 和原因。
- 未配置 webhook 时只能记录 `dry-run`。
- 群内 @ 应用触发的任务，也要记录接收、完成、阻塞或待确认结果。
- 不记录 Webhook URL、Secret、账号密码、Cookie 或私有环境地址。
