# PR-02233 安全验证弹窗链接 hover 样式修复

## 需求

安全验证弹窗中，右侧“切换为手机验证”和“重新发送”链接在鼠标 hover 时不要显示下划线；颜色和点击行为保持不变。

## 验收

- “切换为手机验证”在默认态和 hover 态均无下划线。
- “重新发送”在默认态和 hover 态均无下划线。
- 两个入口原有颜色、文案、布局和点击行为不变。

## 参考

- 用户提供的截图仅用于定位目标元素，属性为 `context-only`，不扩展需求范围。
