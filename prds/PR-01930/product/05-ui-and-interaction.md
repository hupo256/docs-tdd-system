## 逐屏还原要点（对齐真图）

- **列表页 01**：筛选区 UID / 配置编码 / 手动失效时间(起+止两个输入)；列表左上「手动失效」主按钮（紫）；右上 搜索/重置/导出。13 列：序号、UID、账号(脱敏)、活动名称、配置编号、体验金名称、类型、数量、失效数量、仓位占用、备注、操作人、操作时间。
- **添加弹窗 03**：标题「添加失效任务」；UID(灰字提示+字段后说明)、体验金配置编号(同款)、必填备注(红星+「200字」+placeholder「请输入失效原因」)；底部 取消/确认(主按钮)。
- **批量弹窗 06/07**：标题「批量手动过期」；拖拽区「将文件拖到此处，或点击上传」+支持 .xlsx/.xls/.csv ≤10MB；右上「下载模板」。模板列 uids/couponCode/remark。
- **二次确认 08**：⚠️图标+标题「确认体验金失效操作（不可逆）」；影响用户数、影响总金额、◆可用体验金、◆委托冻结体验金、仓位占用金额(单独，不计入总额)；分隔线下固定提示语；底部 [取消] / [确认失效]。

## 状态

| 场景 | 预期 | 状态 |
|------|------|------|
| loading | 列表/预校验/提交/导出/上传 loading，防重复提交 | 待验证 |
| empty | 搜索无数据展示后台空状态 | 待验证 |
| error | 接口错误展示后端/统一错误；添加弹窗输入保留 | 待验证 |
| disabled | 无权限隐藏/禁用入口；提交中禁用确认 | 待验证 |
| success | 成功 Toast「操作成功」，关闭确认弹窗刷新列表 | 待验证 |
| high-risk | 添加弹窗「确认」只触发预校验+二次确认，不直接执行 | 待验证 |

## 展示规则

| 字段 | 规则 | 空态 |
|------|------|------|
| UID | 精确搜索仅数字 | `--` |
| phone/email | 脱敏展示 | `--` |
| 失效数量 | 8 位小数动态累计 | `--` |
| 仓位占用 | 操作时刻快照，不计入二次确认总额 | `--` |
| 备注 | 必填 ≤200 字 | 为空拦截 |
| UID 输入 | 英文逗号分隔 ≤100；超限「单次操作UID不可超过100个」 | — |
| 配置编码输入 | 英文逗号分隔 ≤100；超限「单次操作批次，不可超过100个」 | — |
| 二选一 | 双空「“用户UID”与“体验金配置编码”不能同时为空，请至少填写一项」 | — |
| 笛卡尔积 | 去重后 ≤10000 才可提交；超「当前待处理配对总量超出 10000条上限，请拆分批次批量上传操作」 | — |
