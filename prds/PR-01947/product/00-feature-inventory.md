## 范围总纲（先读）

- **端**：PRD 4.3 明确「涉及端：App（iOS/Android）、Web；涉及用户：合约跟单用户；本期范围：跟单设置」。本文件只登记 **Web 前台（apps/web）** 落点。
- **前端职责边界**：本需求大量为后端逻辑（保证金三层隔离、杠杆三重 min 钳制、复制仓位判定、最小开仓校验、7.6 交叉场景穷举）。PRD 7.4.5 末尾明确：**「跟单的所有下单只是传参数下单，能不能下单由合约判断，拒绝了把原因告诉用户，跟单不做单独的逻辑判断」**。故 Web 前端职责 = **参数配置 UI + 传参保存 + 展示合约返回的失败原因**，不实现隔离/钳制/复制/最小开仓的业务判定。唯一前端侧即时校验 = 7.4.4 自定义杠杆输入钳制到前端硬限制 1–20x + Toast（表单体验；2026-07-10 需求变更后不再按币对 [Min,Max]）。
- **滑点整条删除**：7.2、6.1 滑点行、术语「跟单滑点」、10.1 验收、八通知全为删除线 `~~...~~`，7.2 标题写明「单独拆需求实现，不放这个需求单号」（对应 PR-2069）。按删除线规则本期**不做**。
