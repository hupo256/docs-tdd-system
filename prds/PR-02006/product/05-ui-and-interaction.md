# PR-02006 UI And Interaction

## Header TradFi 浮层

- 触发：鼠标 hover 顶部导航「合约交易」下的 TradFi 菜单显示浮层。
- 分类：第一项为「全部」，后续为后台 TradFi 标签；无有效币对的标签隐藏。
- 搜索：placeholder 为「搜索」；在当前分类范围内实时模糊匹配交易对名称 / 附属名称。
- 搜索联动：切换 Tab 时保留关键词并在新分类下重新检索；鼠标移出搜索框并再次 hover 时初始化为全部 + 空关键词。
- 空态：无匹配时展示「暂无数据」或 UI 指定空态。
- 列表：logo、交易对名、24h 成交额、附属名称标签、最新价、24h 涨跌幅。
- 点击：点击交易对关闭浮层并跳转对应交易页。

## 交易页交易对弹层

- 打开方式：PRD 红框点位要求 hover 显示浮层，不再依赖点击后显示。
- 板块 Tab：展示存在有效币对的板块；TradFi 来源于合约后台币对所属板块。
- TradFi 内分类：全部 + TradFi 标签，隐藏无有效币对标签。
- 24h 成交额：新增标题和列，支持三态排序：降序 → 升序 → 默认；与其他排序字段互斥。
- 别名标签：只显示本需求的币种别名标签，去掉原有标签。

## TradFi 落地页

- 资产基础信息新增「永续」标签和「附属文案」标签。
- 去掉原有标签，只保留本需求提到的别名 / 永续标签。
- 可交易资产表新增 24h 成交额列和排序 icon。
- 24h 最高价 / 24h 最低价新增排序 icon。
- 分页切换需避免自动跳转或异常滚动。
- H5 同步处理：表格密集信息需卡片化或横向规则确认，不允许溢出破版。

## 行情 TradFi 板块

- 资产项新增附属文案标签，取币种别名。
- logo 样式按 PRD 图二优化；缺 UI 节点时需产品 / 设计确认具体尺寸、圆角、背景。

## Admin 币种配置

- 添加 / 编辑币种新增归属板块单选：USDT本位、TradFi。
- 归属板块为 TradFi 时展示币种别名多语言配置区域。
- 语言 Tab / 输入框根据后台国家语言动态渲染。
- 常驻提示语：`TradFi 品种需配置多语言别名，将在对应语言环境下展示`。
- 未填语言项时，失焦或保存均需触发校验；提示：`Please fill in all national language aliases`。

## 主题与响应式

- 涉及 Web 展示均需覆盖 dark / light。
- H5 390px 必测；PRD 明确「h5 都需要处理」。
- 使用现有 Tailwind 语义 token，不因单页改全局 preset。
