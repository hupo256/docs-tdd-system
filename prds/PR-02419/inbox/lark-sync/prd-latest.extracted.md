# PR-02419 公司做市用户禁止修改用户类型（前端范围）

## R1 单个用户设置类型拦截

在运营后台「用户管理 → 用户详情/用户列表」的单个「设置类型」弹窗中，运营点击「确认」保存用户类型时，前端先校验目标用户：若该用户当前账户类型判定为公司做市用户，则阻止本次保存，弹出 toast「该用户为公司做市用户，禁止修改用户类型」，用户类型保持原值；提示关闭后运营仍可继续查看用户信息。非公司做市用户不适用本拦截，继续沿用现有用户类型修改流程。

## R2 批量入口拦截与部分失败提示

在运营后台「用户管理 → 批量设置类型」和「用户管理 → 用户批量管理」两个批量入口提交用户类型修改时，前端逐个校验所选用户：命中公司做市用户的条目修改失败、其余条目正常成功；本次操作完成后以 toast 列出修改失败的用户 UID（形如「11111111，22222222 修改失败」）。

## 识别依据

以用户当前账户类型作为公司做市用户的权威识别依据：账户类型判定为公司做市用户即命中禁止修改规则。账户类型数据沿用现有用户列表/详情接口返回的字段（接口文档后补，作参考，不阻塞 PRD-first 实现）。

## 非前端范围（本期不做）

服务端修改保护（接口独立校验、错误码与错误信息）、历史数据处理、操作日志、埋点与灰度与回滚均不在本期前端范围，本期前端不做这些改动。
