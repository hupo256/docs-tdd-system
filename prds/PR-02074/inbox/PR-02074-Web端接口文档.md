# PR-02074 Web 端接口文档

## 变更范围

Web 本期新增事件搜索，并调整事件列表的固定分类筛选语义。订单创建、订单查询、持仓和结算等既有 Web 接口的请求/响应结构没有变化；本轮新增的 `conditionId/tickSize` 属于 Spot → Node 内部协议，Web 不得传入。

通用请求头：

| Header | 必填 | 说明 |
| --- | --- | --- |
| `exchange-language` | 建议 | 当前界面语言；搜索和返回标题以该值为准，缺失时使用系统默认语言 |
| `timezone` | “进行中”必填 | 用户时区，供体育“进行中”计算本地当天 00:00；不信任 body 中的 timezone |
| `X-Time` | 使用签名时必填 | 毫秒时间戳，有效期 5 分钟 |
| `X-Sign` | 按公共网络层策略 | 请求签名；前端复用现有公共签名组件，不在页面代码维护 `app_key` |
| `exchange-token` | 否 | 本文行情、搜索、分类树和预计收益接口不要求用户登录 |

`timezone` 必须是 Java `ZoneId` 可解析值，例如 `Asia/Shanghai`、`America/New_York`、`UTC+08:00`；“进行中”缺失或格式错误时返回参数错误。

鉴权说明：以上接口都经过 Web 全局 `ApiAuthInterceptor`。当前兼容逻辑在 `X-Sign` 缺失时放行；如果传入 `X-Sign`，必须同时传 5 分钟内的 `X-Time` 且签名正确，否则返回 HTTP 401、业务码 `100155`。前端应统一复用现有请求签名中间件，不应依赖省略签名的兼容行为。

## 1. 事件搜索（新增）

`POST /polymarket/searchEvents`

```json
{
  "keyword": "意大利",
  "currentPage": 1,
  "pageSize": 5
}
```

参数：

| 字段 | 类型 | 必填 | 规则 |
| --- | --- | --- | --- |
| `keyword` | string | 否 | trim 后搜索当前界面语言标题，最多 50 个 Unicode 字符；空字符串返回空列表 |
| `currentPage` | integer | 否 | 默认 1，小于 1 时按 1 |
| `pageSize` | integer | 否 | Web 联想建议 5；完整结果建议 50；服务端限制 1～50 |

`data`：

```json
{
  "list": [],
  "count": 0,
  "currentPage": 1,
  "pageSize": 5
}
```

排序：命中去重字符数降序、首个命中位置升序、推荐状态、结束时间、事件本地主键。返回列表元素沿用既有 `PolymarketEventMarketInfoRes`，没有为搜索单独新增响应 DTO。

## 2. 事件列表（接口不新增，筛选语义变化）

`POST /polymarket/getTagEventsList`

沿用既有请求体。与本期有关的字段：

```json
{
  "pageNum": 1,
  "pageSize": 20,
  "tableType": 1,
  "tagType": "sports",
  "tagTypeTow": "in_progress",
  "tagTypeThree": null
}
```

- `tagTypeTow=all`：忽略二级分类条件，查询一级分类下全部可用事件。
- `tagTypeTow=in_progress`：强制按 `tableType=1` 处理，从 `timezone` 所代表的用户本地当天 00:00 起查询仍可下注的体育比赛。
- `locale`、`timezone` 即使出现在 body 中也不作为可信值，分别由 `exchange-language`、`timezone` 请求头覆盖。
- 响应仍为既有 `data.total`、`data.list`，结构不变。
- 列表和搜索只返回至少包含一个 `active=true、closed=false、acceptingOrders=true` 可下注市场的事件。
- 事件元素新增 `tagTypeThree`，体育聚合可使用 `tagTypeTow/tagTypeThree` 取得“足球｜中超”等完整分类层级。

## 3. 分类树（协议不变）

`GET /polymarket/category/tree`

接口路径和返回结构不变；显示语言以 `exchange-language` 请求头为准。历史 `appLocale` query 参数保留兼容，但不应再作为 Web 的语言来源。

## 4. 预计收益（响应扩展）

`POST /polymarket/getEstimatedProfit`

请求字段保持不变，`marketId/tokenId/side/amount` 均由服务端严格校验。市场不可交易、token 不属于市场或金额超出配置范围时返回参数错误，不再成功返回 `data=null`。

`data` 在旧字段基础上新增：

```json
{
  "currentPrice": "0.50",
  "expectedPrice": "0.52500000",
  "grossAmount": "100",
  "platformFee": "10.0000",
  "polymarketFee": "0.950000",
  "netOrderAmount": "89.05000000",
  "estimatedShares": "169.61904761",
  "estimatedPayout": "169.61904761",
  "estimatedProfit": "69.61904761"
}
```

预计收益和真实 BUY/SELL 下单共用 `PolymarketTradeQuoteService`，费用与舍入口径一致。
