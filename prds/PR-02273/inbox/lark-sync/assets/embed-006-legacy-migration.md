# 存量增强体验金处理（PRD 内嵌 sheet ZyNhs5EnZhVj4btmidnlNS4VgAh / 2RqIBu）

> 由 `lark-cli sheets +cells-get` 读取，2026-08-11。原则：存量不追补、不重算，只对新开仓/新到期生效。多为**后端**迁移口径，前端仅需容忍存量状态与服务端新状态返回。

| 存量类型 | 处理 |
|------|------|
| 待领取（未领） | 状态不变，等用户领 |
| 使用中（已领未开仓） | 状态不变，可继续开 |
| 已使用完（旧逻辑） | 保留原状态，不回退、不强制改 |
| 已失效 | 不变 |
| 已开仓位 | 不强行平仓，按其到期时间自然处理；新规则不追溯旧持仓，旧持仓到强平/到期时按新回收逻辑执行 |
| 旧版 APP 用户 | 服务端按新状态返回，旧版展示不了新字段的 |
