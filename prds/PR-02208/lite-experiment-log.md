# PR-02208 Lite 模式实验记录

## 需求信息

**需求概述**：合约后台新增"API动态费率及返佣"配置功能，并在手续费折扣列表中展示 API 费率信息

**复杂度**：
- 页面数量：2 个页面（配置页 + 列表页修改）
- 文件数量：预计 3-5 个
- API 依赖：需要新增/确认（配置 CRUD API、用户状态查询）
- 风险等级：中（涉及费率配置，业务敏感）

**对比第 1 个实验**：
- 第 1 个：单页面，1 文件，纯前端，无 API
- 第 2 个：双功能，3-5 文件，需 API，有业务规则
- **复杂度提升**：明显更复杂
