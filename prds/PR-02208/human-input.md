# PR-02208 人工提炼

**提炼时间**：2026-09-23  
**提炼人**：AI + 用户协作  
**需求来源**：合约后台 - API 动态费率配置

## 需求概述

合约后台新增"API动态费率及返佣"配置功能，并在手续费折扣列表中展示 API 费率相关信息。

## 提炼要点

### 1. 要做什么？

**需求 1：合约配置 - 新增"API动态费率及返佣"配置页面**
- 展示 L1-L5 五个档位的配置表格
- 每个档位包含：
  - 档位标识（L1-L5）
  - 30天滚动API成交量（USDT）区间配置
  - Maker 费率（百分比）
  - Taker 费率（百分比）
  - 返佣比例（百分比）
  - 操作：编辑按钮
- 支持编辑每个档位的配置

**需求 2：手续费折扣列表 - 新增两列**
- 在现有"手续费率"列后新增：
  - API费率档位（显示 L1-L5 或 "-"）
  - API费率（显示 "Maker X% / Taker Y%" 或 "-"）
- 无 API key 的用户显示 "-"

### 2. 影响哪些文件/组件？

**需求 1**：
- 合约后台 - 合约配置模块
- 预计新增：API动态费率配置页面组件
- 预计文件：2-3 个（页面组件、API 接口、类型定义）

**需求 2**：
- 合约后台 - 手续费折扣列表组件
- 预计修改：列定义，新增两列
- 预计文件：1-2 个（列表组件、列配置）

**总计**：预计 3-5 个文件

### 3. 如何验证？

**功能验证**：
- 合约配置页面存在"API动态费率及返佣"入口
- 点击进入，展示 L1-L5 五档配置表格
- 表格数据正确展示（档位、交易量区间、费率、返佣比例）
- 点击"编辑"按钮，弹出编辑表单
- 编辑并保存，数据更新成功
- 手续费折扣列表新增两列，位置在"手续费率"列后
- 有 API key 用户显示正确的档位和费率
- 无 API key 用户显示 "-"

**边界验证**：
- 编辑时验证 L1-L5 档位不可重复
- 验证交易量区间不得重叠或空档
- 验证 Maker/Taker 费率精度
- 不符合规则时提示："请输入正确的参数"

### 4. 边界条件？

**配置规则**：
- L1-L5 档位不可重复
- 各档位成交量区间必须采用"左闭右开"区间，最后一档为左闭区间
- 成交量区间必须连续，不允许重叠
- Maker/Taker 费率必须满足系统精度要求（需确认精度）
- 返佣比例范围（需确认）

**生效规则**：
- 新规则生效后，仅影响新进入生效周期的费率计算
- 不符合上述规则，统一报错："请输入正确的参数"

**数据展示**：
- 无 API key 用户：API费率档位和API费率均显示 "-"
- 有 API key 用户：根据实际档位展示数据
