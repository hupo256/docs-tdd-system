| Hero 深色带 | 活动头部保持 Figma 深色 Hero（`bg-4` + `text-6`），不随页面浅色区反转 |
| 避免 | 硬编码 `#7132f4` / `#8d91a5`；全量 `dark:` 前缀（除非单点特例） |

### 11.2 Mobile Web（对齐项目惯例）

**参考模块**：

| 模块 | 路径 | 可复用点 |
|------|------|----------|
| 福利中心 | `apps/web/src/apps/Rewards/` | 任务卡片 `flex-col md:flex-row`、容器 `max-w-[1200px] px-4 xl:px-0`、按钮禁用 token |

**断点**（与 `useViewportSize` 默认一致）：

| 断点 | 宽度 | 用途 |
|------|------|------|
| Mobile | ≤ 768px | `isMobile` / `isMobileLayout` |
| Tablet | 769–1024px | `isTablet` |
| Desktop | > 1024px | 按 Figma 1200 内容宽 |

**布局约定**：

```text
页面容器    mx-auto w-full max-w-[1200px] px-4 md:px-6 xl:px-0
Hero        flex-col md:flex-row；移动端正文全宽，头图居中且 max-w-full
任务卡片    flex-col md:flex-row；奖励区移动端正文上方；按钮 w-full md:w-[160px]
子活动标题  移动端正文左对齐或保持居中（与 Rewards 标题一致用 text-left md:text-center 待实现时按截图）
阶梯 stepper 移动端允许横向滚动 overflow-x-auto，避免挤压档位
排行榜表格  外层 overflow-x-auto；移动端正文缩小字号可用 text-body-s md:text-body-regular
底部浮层    移动端 `w-[calc(100%-32px)]`，桌面 `max-w-180`，固定底部并考虑 safe area
分享/拦截弹窗  max-w-[min(92vw,400px)] mx-4
```

**行为层**：

- JS 侧确需区分移动/桌面时，使用项目已有 viewport hook；优先用 Tailwind 断点完成布局。
- 需要顶/底安全区时用 `useSafeAreaSurface`（Hero 深色底、底部浮层）。
- **不** 新建 `/m/campaign/...` 路由；Mobile Web 与桌面共用 `campaign/[activityId]`。

**代码落点**（见 `02-technical-design.md`）：

- 页面容器：`Campaign/index.tsx`
- hook：`useCampaignBottomCta.ts` 负责滚动阈值显示逻辑
- 任务按钮：`CampaignStatusCta.tsx` 复用主按钮、任务按钮和底部浮层按钮
