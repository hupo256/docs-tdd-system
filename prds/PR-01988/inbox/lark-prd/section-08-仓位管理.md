位置：管理后台 → 预测市场 → 仓位管理。新增页面，对齐需求文档 5.8 仓位字段定义，按用户持仓维度聚合（订单维度见订单管理）。

1. 搜索项

支持按：状态（持仓中/提前卖出平仓/到期平仓）、UID、仓位ID、创建时间区间、最后更新时间区间检索；支持导出 CSV。

1. 列表字段

| **字段** | **取值** | **说明** |
|-|-|-|
| 仓位ID | 字符串 | 仓位唯一标识 |
| UID | 字符串 | 持仓用户 |
| 事件 / 方向 | 文本 / yes·no | 事件名 + 持仓方向 |
| 保证金(USDT) | 数值 | =Σ 用户下注金额（加仓累加） |
| 份额 | 数值 | 该事件该方向当前持有份额 |
| 平台收入 | 数值 | 买入/卖出/结算三类收入加总 |
| 创建时间 | 时间 | 建仓时间 |
| 最后更新时间 | 时间 | 相同市场相同方向，视为一个仓位  <br/>最后更新时间为最近一笔成功订单（买入/卖出/结算）的结束时间 |
| 状态 | 持仓中/已平仓 | 仓位生命周期状态 |
