## 流程重建

```
开始 → 点击第三方登录 → 第三方 OAuth 授权 → 判断是否已绑定
├─ 已绑定 → 账号状态判断（调用当前逻辑：账号是否存在/注销冻结、是否已绑 TG 第三方、密码是否正确、安全验证码是否正确等）
│          ├─ 冻结 → 返回冻结提示
│          ├─ 注销 → 返回注销提示
│          └─ 正常 → 安全校验（滑块校验 / 验证码校验）→ 登录成功
└─ 未绑定 → 判断平台是否有一致邮箱注册账号
           ├─ 有 → 走强制关联流程 → 输入密码 → 安全校验 → 完成并登录（关联成功）
           └─ 无 → 选择：注册 / 关联
                   ├─ 注册 → 填写邮箱或手机号 + 同意条款 → 滑块/验证码校验 → 调用当前注册逻辑（查重、验证码校验）
                   │         → 平台为用户创建交易所账户并绑定第三方平台登录 → 登录成功
                   │         → 个人中心提示设置登录密码 / 账户管理（App：安全中心提示设置密码）
                   └─ 关联 → 输入邮箱或手机号 + 输入密码 → 安全校验 → 关联成功
```

## 与实现对应

- `判断是否已绑定 / 账号状态` → 后端 `authStatus` 三态：1 已授权直登、2 已注册未授权（强制关联）、0 未授权未注册（选择注册/关联）。
- `安全校验（滑块/验证码）` → 极验 GtType + 邮箱/短信/Google 验证码优先级（F11）。
- `平台创建账户并绑定第三方` → `/fe-ex-api/oauth/authRegister`；`强制关联/关联` → `joinAddAccount` / `internalJoinAuth`。
- `个人中心提示设置登录密码` → F09 个人中心账户绑定。

白板未引入功能清单之外的新分支，F01–F05 已覆盖。
