### 2. 活动规则「5. 奖励发放与使用说明」

**位置**: 所有福利中心活动页面的规则说明

**改动**: 替换整段文案

**新文案**:
```
本活动奖励包括合约体验金、合约增强体验金、合约赠金、合约抵扣金、手续费抵扣金、
手续费返现卡、现金红包等，具体奖励类型及金额以页面实际展示为准。

各类奖励的适用范围、使用条件、有效期、抵扣/返现规则等，以实际发放卡券的规则说明为准。
奖励领取后可前往【卡券中心】查看及使用。

福利中心发放的交易类卡券权益仅支持非 API 交易使用，通过 API 产生的交易不享受对应卡券权益。
```

**关键新增**: 最后一句关于 API 交易的说明
