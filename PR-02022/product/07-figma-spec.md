## 2. 引导整体结构（driver.js 形态）

设计稿「跟单引导」页图层结构印证引导 = **全屏深色遮罩 + 挖空高亮 + popover 气泡**，即 driver.js 的标准能力：

| 图层 | 作用 | 关键值 |
|------|------|--------|
| `Subtract`（= `Rectangle 346273848` − `Rectangle 346273849`） | 全屏遮罩挖空高亮区 | 遮罩 fill `var(--BG-6)` ≈ `rgba(11,12,14,0.x)` 半透明深色；尺寸同画板 |
| 高亮占位 `Rectangle`（如 132×72 `#D9D9D9`） | 标记被高亮的真实页面元素位置 | driver.js 自动按目标元素计算，无需手写 |
| 「引导样式」图层组 | popover 气泡 + 箭头 + 按钮 | 见 §3 |

> **结论**：用 driver.js 接管「遮罩 + 挖空 + 高亮描边 + popover + 箭头」，业务侧只需提供高亮目标元素选择器和 popover 内容/按钮回调。详见 [02-technical-design.md](./02-technical-design.md)。

## 3. 引导 popover 规格（核心还原模块）

### 3.1 视觉结构（三步共用同一气泡组件，差异在按钮与文案）

```
┌─────────────────────────────┐
│ N/3  <标题>                  │   ← 步骤指示 + 标题（白，加粗）；第三步右上角有 ×
│ <正文说明>                    │   ← 正文（次级灰）
│ 跳过            上一步 下一步  │   ← 按钮行
└──────────▽──────────────────┘   ← 指向高亮元素的小三角箭头
```

| 1 | 9679-22600 | 1/3 | 选择带单员 | 从众多优质交易员中，挑选最适合你的 | 跳过 | 下一步（紫） | 无 |
| 2 | 9681-17438 | 2/3 | 一键配置，轻松入场 | 设定跟单金额及相关参数，立即跟单 | 跳过 | 上一步 / 下一步（紫） | 无 |
| 3 | 9681-19086 | 3/3 | 跟单进展，尽在掌握 | 实时查看持仓与收益，随时调整跟单策略 | —（无跳过） | 上一步 / 完成（紫） | **去掉**（见下） |

> ✅ **已确认（2026-06-30）**：第三步 popover 右上角 `×` **去掉**，第三步仅保留「上一步 / 完成」（与 PRD §5.1 一致）。Figma 稿上的 × 不实现。

### 3.3 popover 样式落盘（视觉描述 + 待量取）

| 项 | 视觉判断 | preset / 待量取 |
|----|---------|----------------|
| 背景 | 深色不透明气泡（比遮罩略浅的深灰） | 量取色值 → 映射 `bg-*` token |
| 圆角 | 中等圆角 | 量取 cornerRadius → `rounded-m`/`rounded-lg` |
| 内边距 | 约 16-20px | 量取 padding |
| 标题字号 | body/标题级，白色加粗 | 量取 fontSize → preset |
| 正文字号 | body-s，次级灰 | 量取 → `text-text-3` 类 |
| 主操作（下一步/完成） | 紫色文字/按钮 | 品牌紫 token（与「立即登录」紫一致） |
| 次操作（跳过/上一步） | 次级灰文字 | `text-text-3` 类 |
| 箭头 | 小三角，与气泡同色，指向高亮元素 | driver.js 自带，套色 |

> driver.js popover 为自定义 HTML/CSS，通过 `popoverClass` + 项目 Tailwind class 还原上表；精确 token 在 G4 实现该控件前用 Dev Mode 逐项量取并回填本表，G6 L2 并排校准。

## 5. 带单员强提醒弹窗规格（node 9681-25408）

### 5.1 视觉结构

```
┌───────────────────────────────┐ ×
│        ┌─────────┐             │
│        │ 卡片图标 │✓(绿勾徽章)  │   ← 顶部成功插图
│        └─────────┘             │
│            恭喜您               │   ← 标题（居中，白，加粗）
│  您已成为合约带单员！完成首笔     │   ← 正文（居中，次级灰）
│  带单后，您的主页将正式展示在     │
│  带单员列表中，赶快开始您的       │
│  第一笔带单吧！                  │
│  ┌───────────────────────────┐ │
│  │         去带单            │ │   ← 主按钮（紫色全宽，圆角）
│  └───────────────────────────┘ │
└───────────────────────────────┘
```

### 5.2 样式落盘

| 项 | 视觉判断 | 实现 / 待量取 |
|----|---------|--------------|
| 容器 | 居中 Modal，全屏深色遮罩 | **复用 `components/Modal.tsx`**（`isDismissable=false` 实现点击遮罩不关闭） |
| 宽度 | 约 444px（画板提示 w-360 为内容区） | 量取后用 Modal `size` 或自定 |
| 右上 × | 关闭按钮 | Modal 自带 close |
| 成功插图 | 深色卡片图标 + 绿色 ✓ 徽章 | 需 UI 切图 / 现有 icon 组合（G4 确认资源） |
| 标题 | 居中加粗白 | 量取 fontSize |
| 正文 | 居中次级灰 | `text-text-3` 类 |
| 去带单按钮 | 紫色全宽圆角 | 品牌紫 token + 全宽 |

> 点击遮罩不可关闭（PRD §5.2）→ Modal `isDismissable={false}`。
