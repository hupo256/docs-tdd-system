## 8. 行情板块（PRD 5.5）

> **范围更新（2026-06-10）**：5.5 纳入本期，实现在 **Markets 行情页**，不是 TradFi 落地页内嵌模块。

PRD 规则：

| 项 | 规则 |
| --- | --- |
| 板块 | `TradFi` |
| 数据源 | 合约管理后台 → 币对 → 板块名称（`configSectionList` + `sectionIds`） |
| 入口 | Markets 主 Tab：`自选 / 现货 / 合约 / TradFi` |
| 路由 | `/markets/tradfi` |
| 子 Tab | 默认 `全部`；动态来自 `symbolTag`（股票 / 贵金属 / 商品 + 后台新增） |
| 搜索 | 顶部「搜索币种」过滤**当前子 Tab 区域**内的交易对（复用 Markets `SearchInput` store） |
| 列表 | 复用 `MarketTable`（swap 列：名称 / 价格 / 24h 涨跌 / 最高 / 最低 / 走势 / 交易） |

与 5.2 可交易资产的关系：

- **5.2**：TradFi 落地页 `/tradfi` 内的可交易资产表格（含分页、排序）。
- **5.5**：Markets 行情页独立 Tab，共享同一套 `public_info` + ticker + kline 数据映射。
