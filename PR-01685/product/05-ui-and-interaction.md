## 3. 页面结构

PRD 定义：

```text
活动落地页 = 活动 Banner 位 + 子活动（内含任务组合） + 活动规则
活动 → 活动 Banner 位 → 子活动 → 任务组合 → 任务条件 → 奖励
```

Web 页面结构（与 Figma 整页效果图 `9517:137713` / `9364:134676` 一致，见 [07-figma-spec §2.1](./07-figma-spec.md)）：

1. **Hero / Banner**（1512×480，深色带，不随主题反转任务区样式）
2. **子活动列表**（内容区 1200px 居中，块间距 80px；Hero 与首块间距 60px）
   - 每个子活动：标题区（68px）+ 任务组合（间距 30px）
   - 整页示例顺序：单一任务×3 → 进阶任务 → 阶梯任务 → 组合任务 → 排行榜
   - 实际顺序与组合由后台配置，组件按 `taskType` 渲染即可
3. **活动规则区**（大标题 + 多段正文，完整展开）
4. **底部浮层 CTA**（700×60，滚动后顶部主按钮不可见时展示）

页面级间距 token：`gap-[60px]`（Hero 下）、`gap-[80px]`（子活动间）。

## 6. 任务组合 UI

### 6.1 单一任务

> Figma：`9489:136580` / `581` / `582` 为 **3 种不同单一任务示意**（KYC、合约交易量、净充值），非状态变体。详见 [07-figma-spec §4.3](./07-figma-spec.md)。

展示：

- 奖励内容：如 `10 USDT 合约体验金`
- 条件标题：≤ 30 字符，单行省略
- 条件副标题：≤ 2 行，多出省略；不配置不展示
- 条件类型：KYC / 净充值额 / 累计充值额 / 现货交易量 / 合约交易量
- 数值条件进度条与 `当前值/目标值 USDT`
- 操作按钮：去完成 / 待领取 / 已领取 / 已发放 / 待发放 / 已结束

### 6.2 阶梯任务

> Figma：`9489:136583` / `594` / `607` 三列为 **第 1/2/3 阶段示意**（高亮档=当前阶段）。详见 [07-figma-spec §4.5](./07-figma-spec.md)。

适配：多个档位，按最高档发放，不叠加奖励。

规则：

- 可配置 2-8 个档位。
- 每个档位 2-3 个条件，条件之间为 AND。
- **阶段解锁**：须完成上一阶段/档位后，才能进入下一阶段；stepper 高亮表示当前阶段。
- 完成某档位后，对应档位按钮变为待领取。
- 直接达成高档时，可直接领取最高档；低档不叠加。
- 鼠标移至档位时展示 Popover（`9244:132579`），多行展示该档位条件名称

### 6.3 进阶任务

> Figma：`9489:136618` / `625` / `634` · 三列同为阶段 1/2/3 示意，结构同阶梯。详见 [07-figma-spec §4.6](./07-figma-spec.md)。

适配：逐档解锁，可叠加领取。

规则：

- 可配置 2-8 个档位。
- 每档 2-3 个条件，条件之间为 AND。
- **阶段解锁**：同阶梯，上一阶段完成后才进入下一阶段；高亮档=当前阶段。
- 达成第 N 档后，第 N 档可领取，后续档位继续进行中。
- 领取第 1 档后，不影响继续领取第 2 档。

### 6.4 组合任务

> Figma：`9489:136730` / `732` / `731` · 三列同为阶段 1/2/3 示意；含奖励区 + 多条件 + 进度条 + 「且」连接圆。详见 [07-figma-spec §4.4](./07-figma-spec.md)。

适配：2-3 个条件，支持 AND / OR。

| 组合逻辑 | 完成规则 |
|----------|----------|
| AND | 条件全部达成才可领取 |
| OR | 任意条件达成即可领取 |

### 6.5 排行榜任务

> Figma：`9489:136673` · 1200×943 · 含我的数据条 + 说明 + 10 行表格 + Pagination。详见 [07-figma-spec §4.7](./07-figma-spec.md)。

模块：

1. 当前用户数据
   - 排名：未报名 / 未上榜 `-`；1000 名以上 `1000+`；数值 **32px Bold**
   - 排名指标：总交易量、现货交易量、合约交易量、收益额、亏损额
2. 奖励说明
   - 后台纯文本，完整展示
3. 排行榜
   - 排行榜标题
   - 更新频率 + 最近更新时间
   - 排名：前 3 名显示奖牌
   - UID：脱敏，如 `*1292`
   - 指标值：千分位，保留 2 位小数
   - 分页：每页 10 条，含跳页输入框（40×24）
   - 暂无数据空态

## 9. Loading / Empty / Error

| 场景 | 表现 |
|------|------|
| 首次加载 | 骨架屏，模拟页面结构 |
| 活动详情失败 | 错误提示 + 重试按钮；主按钮状态不变（若已有旧数据则保留） |

## 11. 主题与响应式

### 11.1 深/浅色主题

- **必须** 同时支持浅色与深色；无独立 Figma 深色画板。
- 实现使用项目语义 Tailwind token（`bg-1`、`text-1`、`text-3`、`bg-brand-1`、`border-divider-2` 等），由 `globals.css` 的 `.dark` 切换。
- Figma MCP 参考代码中的 `var(--bg-1)` 等 **必须映射为语义类**，不得保留硬编码 hex。
- 活动 Hero 区保持固定深色带（`bg-4` + 浅色字），与任务区随主题变化区分。
- 按钮不可用态参考福利中心：`disabled:!bg-cc-2 disabled:!text-3`（见 `Rewards/utils/taskActionButtonClasses.ts`）。

整页走查基准：浅色 `9517:137713`、深色 `9364:134676`。详见 [07-figma-spec §2.1](./07-figma-spec.md)、[§11.1](./07-figma-spec.md)。

### 11.2 Mobile Web

- **同路由** `/campaign/[activityId]`，不另建 `/m/` 活动页。
- **无** 独立 Figma 移动稿；按项目现有 Web 响应式惯例处理，优先使用 Tailwind 断点和语义 token。
- 断点：`useViewportSize` 默认 mobile ≤768px、tablet ≤1024px。
- 核心规则：
  - 页容器：`max-w-[1200px] mx-auto px-4 md:px-6 xl:px-0`
  - 任务卡片：移动端纵向堆叠，操作按钮 `w-full md:w-[160px]`
  - Hero：移动端文案与 CTA 在上、头图在下或缩放
  - 阶梯档位：移动端可横向滚动
  - 排行榜：表格外层 `overflow-x-auto`
  - 底部浮层：移动端全宽贴底 + safe area

详见 [07-figma-spec §11.2](./07-figma-spec.md)。
