# docs_tdd v4.0 — 效率优先 + 准确性保底

> 发布日期：2026-09-23  
> 版本：v4.0.0  
> 状态：实现完成，待验证

---

## v4.0 目标

解决 v3.5 的三大痛点：

1. **小改动用大量时间和 token**（当前 8 分钟 → v4.0 < 2 分钟）
2. **提测时漏明显功能**（extraction/coverage 质量不够）
3. **Claude/Codex 变慢**（全量加载规则，context 过重）

核心策略：**先建轻通道（效率止血），再加强守卫（准确性保底）**。

---

## 四个核心改进

### 1. lite-path 真正可执行（动作 2）

**文件**: `common/engine/agent-scripts/lib/lite-path-executor-v4.mjs`

**功能**: 
- 当 `lite-path-router` 判定低风险场景时（纯文案/样式/typo），直接执行快速通道
- 跳过 extraction / coverage review / scope approval
- 产出最小 work-item.json（1 个 requirement + 1-3 surface）
- 全程 < 2 分钟

**适用场景**:
- ✅ 纯文案修改（改按钮文案、提示语）
- ✅ 样式调整（颜色、间距、字号）
- ✅ typo 修复（拼写错误）
- ❌ 涉及资金、权限、登录、不可逆操作（黑名单一票否决）
- ❌ 文件数 > 3 个

**使用**:
```bash
# 自动判断（推荐）
docs-tdd kickoff PR-02440 --prd "把首页按钮文案改成'立即开始'" --intent "改文案"

# 强制 lite
docs-tdd kickoff PR-02441 --force-lite --prd "..." --intent "样式调整"
```

---

### 2. 规则按档位裁剪加载（动作 3）

**文件**: `common/engine/agent-scripts/lib/rule-loader-v4.mjs`

**功能**:
- 按 `efficiencyRoute` (micro/lite/standard/high-risk) 选择加载哪些规则文件
- micro: 3 个文件（git-branch-flow + biome + 核心清单），12K 字符
- lite: 5 个文件（+ 项目 README + 共享组件），24K 字符
- standard: 8 个文件（+ api/i18n/state），80K 字符
- high-risk: 12 个文件（+ figma/security/test/a11y），160K 字符

**效果**: Claude/Codex prefill 时间从 30 秒降到 5-10 秒（lite 档）

**使用**:
```javascript
import { generateRuleContext } from './rule-loader-v4.mjs'

const ruleContext = generateRuleContext('lite', {
  extraTags: ['api'],  // 如果需要 API 规则，追加
})
```

---

### 3. precommit 守卫分档（动作 4）

**文件**: `common/engine/agent-scripts/precommit-verify-code-rules.mjs` (已修改)

**功能**:
- 读取 `work-item.json` 的 `efficiencyRoute` 字段
- micro/lite 档：只跑 Biome + git diff --check，跳过完整 checkpoint 守卫
- standard/high-risk 档：走完整守卫（当前逻辑）

**效果**: lite 档 commit 从 20 秒降到 < 2 秒

**使用**: 无需手动调用，git commit 时自动触发

---

### 4. kickoff 默认 v2 + lite-path 判断（动作 1）

**文件**: `common/engine/agent-scripts/lib/kickoff-v4.mjs`

**功能**:
- 废弃 v1（除非显式 `--force-v1`，将在 v4.1 移除）
- 新需求默认 v2 workflow
- 自动调用 `lite-path-router` 判断是否适合快速通道
- 适合则走 `lite-path-executor-v4`，否则走标准 v2 流程

**使用**:
```bash
# v4.0 kickoff（推荐）
node common/engine/agent-scripts/lib/kickoff-v4.mjs PR-02440 \
  --prd "把首页按钮文案改成'立即开始'" \
  --intent "改文案"

# 或通过 docs-tdd.mjs（待集成）
docs-tdd kickoff PR-02440 --prd "..." --intent "..."
```

## 集成到 docs-tdd.mjs

需要修改 `docs-tdd.mjs` 的 kickoff 分支，调用 `kickoff-v4.mjs` 而非 `project-orchestrator.mjs`：

```javascript
// 在 docs-tdd.mjs 约 275 行
if (command === 'kickoff') {
  // v4.0: 使用新 kickoff
  const kickoffV4 = join(scriptDir, 'lib', 'kickoff-v4.mjs')
  process.exit(run([kickoffV4, projectId, ...cliArgs.slice(2)]))
}
```
