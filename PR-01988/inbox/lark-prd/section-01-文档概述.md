# **文档概述**

## **背景**

一期已完成预测市场核心交易链路：体育事件行情同步、市价买入/卖出、到期结算、资金冻结/解冻、5 分钟自动对账、链上钱包监控与 Web/App 前端。一期已具备“能跑通交易”的能力，但运营侧仍缺少数据可见性、收入可量化、异常可处置的工具。

二期目标是补齐运营与风控的“后台能力闭环”，让平台可观测（埋点+统计）、可处置（事件管理+手动平账）、可预警（告警配置），从而支撑规模化放量。三期面向商业化与体验升级。

## **二期范围一览**

| **模块** | **内容** |
|-|-|
| 数据埋点 | 前端+服务端双埋点，覆盖曝光、点击、下单漏斗、成交结果与结算，支撑转化分析与收入归因 |
| 每日收入统计 | 管理后台新增每日收入统计页（三类收入、成本、毛利） |
| 事件管理 | 添加事件；上线/下线、开启/关闭交易；事件级三档 rate；多级分类 |
| 订单管理 | 管理后台新增订单列表页，对账用 |
| 仓位管理 | 管理后台新增仓位列表页（用户持仓维度） |
| 手动平账 | 持仓不平时人工发起 FOK 平账，过程不产生新用户订单 |
| 告警配置 | 钱包余额告警、下单失败告警阈值与 Lark 通知渠道可配置化 |



## **1.3 目标与不做的事**

**二期做：运营可观测、可处置、可预警的后台工具。**

- 让运营/财务能看清订单与每日收入毛利。
- 让运营能手动控制事件可见性与可交易性。
- 让技术能在持仓不平时安全手动平账。
- 让告警阈值从硬编码变为后台可配置。

**二期不做：用户侧新交易玩法、限价单、自动补资、多语言法币结算、理财沉淀收益核算（列入三期候选）。**
