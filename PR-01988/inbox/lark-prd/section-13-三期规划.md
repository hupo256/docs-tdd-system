# **三期规划**

以下三期候选基于需求文档中标注的“待办/缺口/后期”项，以及二期落地后的自然延伸，按价值与依赖给出优先级建议，供评审筛选。

**候选清单与优先级**

| **方向** | **内容** | **来源** | **优先级** |
|-|-|-|-|
| 自动补资 | 钱包余额触发紧急告警时自动从主钱包补充 USDC/POL，替代纯人工 | 文档8.4 | P0 |
| 差异化运营 | 加价率/抽水率从 KV 迁移到配置中心，按分类/事件/活动批量配置与灰度 | 文档5.7 | P0 |
| 多事件品类扩展 | 从仅体育扩展到加密、政治、金融等品类，行情接入与结算规则适配 | 文档4 | P1 |
| 资金沉淀理财 | USDT 余额沉淀理财收益核算与入账，纳入收入统计第四类 | 文档1.2 | P1 |

**建议排期思路**

- P0 先行：自动补资 + 配置中心，直接降低运营人力与资金风险，依赖二期告警与事件管理已就绪。
- P1 并行：品类扩展与理财收益提升营收天花板；体验升级与合规增强提升留存与稳健性。
- P2 探索：限价单与自动平账技术复杂度高，放在体量验证后再投入。

**三期成功度量**

- 运营人力：补资/平账人工操作次数下降 ≥ 70%。
- 营收：非体育品类贡献收入占比 ≥ 30%；理财沉淀收益入账。
- 体验：下单漏斗买入成功转化率提升，持仓相关推送打开率达标。自动补资
