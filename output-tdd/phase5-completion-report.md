## 🎯 核心功能

### 智能规则选择

**当前问题**: 每次都注入全部规则，即使只需要一小部分

**优化方案**: 根据验证级别和需求信号智能选择

```javascript
V0-lite (快速通道):
  - 核心规则
  - ~500 tokens
  - 减少 90%

V0 (单模块低风险):
  - 核心 + 质量基础
  - ~1250 tokens
  - 减少 75%

V1 (多模块中风险):
  - 核心 + 质量 + 领域规则
  - ~2500 tokens
  - 减少 50%

V2 (高风险):
  - 完整规则
  - ~5000 tokens
  - 基线
```

### 领域规则智能加载

**信号检测**:
- `hasFunds` → 加载资金领域规则
- `hasPermission` → 加载权限领域规则
- `hasForm` → 加载表单领域规则
- `hasList` → 加载列表领域规则

**按需加载**: 只加载需要的领域规则，不是全部加载

## 🔧 使用示例

### 集成到提取流程

```javascript
import { selectRules, detectSignals, formatRules } from './smart-rules.mjs'

// 在提取阶段
async function extractWithSmartRules(projectId, verificationLevel) {
  // 1. 读取 work-item
  const workItem = readWorkItem(projectId)
  
  // 2. 检测需求信号
  const signals = detectSignals(workItem)
  
  // 3. 智能选择规则
  const ruleSet = selectRules(verificationLevel, signals)
  
  // 4. 格式化规则内容
  const rulesContent = formatRules(ruleSet)
  
  console.log(`📋 注入规则: ${ruleSet.level}`)
  console.log(`   大小: ${ruleSet.size} (~${ruleSet.estimatedTokens} tokens)`)
  console.log(`   包含: ${ruleSet.rules.length} 个规则模块`)
  
  // 5. 注入到 AI prompt
  const prompt = `
${rulesContent}

现在请根据以上规则完成需求分析...
`
  
  return await callAI(prompt)
}
```
