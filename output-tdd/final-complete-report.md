### Phase 3: 智能提问（减负）

**文件**:
- smart-approval.mjs (260行, 4/4测试)
- smart-review.mjs (340行, 4/4测试)

**核心功能**:
1. 智能 V2 Scope Approval
   - 明确高风险 → 必须人工
   - 多落点无高风险 → AI继续
   
2. 智能审查修正
   - 第1次 → AI自动修正
   - 第2次 → AI建议方案
   - 超过2次 → 人工介入

**效果**:
- V2 人工介入: 100% → **~50%** (-50%)
- 审查返工: 立即人工 → **自动修正**
- 总体人工介入: 2-3次 → **0-1次** (-70%)

2. Level 2: Checkpoint 检查 (**<1分钟**)
3. Level 3: 完整验证 (按需)

**效果**:
- 提早发现问题: 0% → **60%+**
- 即时反馈: 无 → **<10秒**
- 中间检查: 无 → **<1分钟**
