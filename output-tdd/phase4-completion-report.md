## 🎯 三级验证体系

### Level 1: 编辑后即时检查（轻量）

**触发时机**: 每次文件编辑后  
**检查内容**:
- ✅ Lint 受影响文件（快速模式）
- ✅ TypeScript 检查受影响文件（增量模式）
- ❌ 不跑测试
- ❌ 不写状态文件

**预期耗时**: < 10 秒

**作用**:
- 立即发现格式和类型错误
- 避免积累小问题
- 快速反馈，提高迭代速度

```javascript
await level1Check(['ModifyPhone.tsx'], { fast: true })

// 输出:
// 🔍 Level 1: 即时检查 (1 个文件)...
//    ✓ 通过
//    耗时: 2.2s
```

---

### Level 2: Checkpoint 检查（中等）

**触发时机**: 逻辑单元完成后  
**检查内容**:
- ✅ Lint 受影响文件
- ✅ TypeScript 检查受影响文件
- ✅ 相关单元测试
- ✅ 写 checkpoint，标记 "partial"

**预期耗时**: < 1 分钟

**作用**:
- 确保逻辑正确
- 单元测试覆盖
- 记录中间进度

```javascript
await level2Check(
  ['ModifyPhone.tsx'], 
  ['ModifyPhone.test.tsx']
)

// 输出:
// 🔍 Level 2: Checkpoint 检查...
//    ✓ 通过
//    耗时: 24.3s
```

---

### Level 3: 完整验证（完整）

**触发时机**: 所有改动完成后  
**检查内容**:
- ✅ 运行所有证据命令
- ✅ 写正式 result

**预期耗时**: 按需（可能 2-5 分钟）

**作用**:
- 完整的质量保证
- 正式验收
- 生成交付证据

```javascript
await level3Check(workItem)

// 输出:
// 🔍 Level 3: 完整验证...
//    ✓ 验证通过 (10/10)
//    耗时: 180.5s
```

## 🔄 渐进式验证流程

```
编辑代码
  ↓
Level 1 即时检查 (<10秒)
  ├─ 通过 → 继续编辑
  └─ 失败 → 立即修正 ← 提早发现！
  
完成逻辑单元
  ↓
Level 2 Checkpoint (<1分钟)
  ├─ 通过 → 继续下一单元
  └─ 失败 → 修正逻辑 ← 提早发现！
  
完成所有改动
  ↓
Level 3 完整验证 (2-5分钟)
  ├─ 通过 → 交付
  └─ 失败 → 深层问题（少数）
```

**关键价值**: 大部分问题在 Level 1/2 发现，不等到最后才失败

## 💡 使用示例

### 集成到编辑流程

```javascript
import { level1Check } from './progressive-verify.mjs'

// 每次编辑后
async function onFileEdit(files) {
  const result = await level1Check(files, { fast: true })
  
  if (!result.passed) {
    console.log('⚠️ 发现问题，请修正')
    showErrors(result)
  }
}
```

### 集成到 Checkpoint

```javascript
import { level2Check } from './progressive-verify.mjs'

// 逻辑单元完成后
async function onCheckpoint(files, tests) {
  const result = await level2Check(files, tests)
  
  if (result.passed) {
    console.log('✅ Checkpoint 通过')
  } else {
    console.log('❌ Checkpoint 失败，请检查')
  }
}
```
